# Security reporting

For a suspected vulnerability or exposed credential, contact
[contact@schooldecider.com](mailto:contact@schooldecider.com) privately. Include the affected
commit, reproduction steps and likely impact. Do not put credentials, personal data or
exploit details in a public issue. Please allow time to investigate before disclosure.

Security fixes target the current `main` branch. This is an independently maintained
project; no response-time guarantee is offered. The repository does not contain the school
database, production environment files or private operational backups.

Dependency limitations and operational controls are recorded in
[the publication checklist](docs/PUBLICATION_CHECKLIST.md).
