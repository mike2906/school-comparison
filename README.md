# Free kindergarten places

Written by `.github/workflows/capture-free-places.yml` on `main` twice a day: today's free
places in every Sofia municipal kindergarten and school preparatory group (ПГУ), as ИСОДЗ
(kg.sofia.bg) shows them. Counts only, nothing about any child. Each commit replaces
`bg/sofia/free-places.json`; the git history is the archive. Docs: `docs/FREE_PLACES.md` on `main`.
